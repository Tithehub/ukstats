# Put the live stream box on ukstats.co.uk

Nothing in the site's settings needs to change. The box only needs publishing, plus one setting in YouTube.

## 1. YouTube Studio (you)
- Open your live stream in YouTube Studio, then **Edit** → **Show more**.
- Tick **Allow embedding**. If it's off, the box on the site shows "Video unavailable".
- Visibility must be **Public**. Unlisted can also play on the site, but Private can't.

## 2. Publish (me)
- First, check the latest preview has no errors and the box shows on the home page.
- Then publish to ukstats.co.uk, which also sends the other preview-only changes live: the Top 6 panel, the stream's stats strip, and the new 2026 clips.

## 3. OBS (you)
- Right-click the UKStats Browser source → **Refresh**, so the stream shows the newest stream page.
