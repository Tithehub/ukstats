# Go live on YouTube

## 1. Put the latest stream on ukstats.co.uk
- Run a fresh security scan (the last one is out of date) and check that nothing critical comes up.
- Publish, so ukstats.co.uk/globe/broadcast shows the newest version: the fixed Top 6 panel with small boats first, the bigger headlines and the 2026-only footage.
- After about a minute, load the live broadcast page once to check it works.

## 2. Your steps on the Mac (I'll guide you live)
1. OBS: add a Browser source at `https://ukstats.co.uk/globe/broadcast`, 1920x1080, 30 FPS, and tick "Control audio via OBS". Mute the mic and desktop audio.
2. YouTube Studio → Create → Go live → Stream: paste the title and description from /globe/studio, set the audience, and choose **Unlisted** for the first test.
3. Paste the stream key into OBS → Settings → Stream. Keep it private and never send it here.
4. Start Streaming. Wait for "Excellent" connection health, then check the globe, the Top 6 panel, the tickers and the clip credits.
5. Once it all looks right, switch to Public (or start a new Public stream with the same settings).

## 3. Point the "Watch live" buttons at YouTube
- Once the stream exists, paste its watch link here (youtube.com/live/... or youtube.com/watch?v=...).
- I'll point both Watch live buttons at that link and publish again.
