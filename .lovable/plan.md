# Let the live stream play on ukstats.co.uk

The website itself needs no changes. Playing on other sites is controlled by YouTube's owner settings. Here is what to switch on:

## 1. This stream (YouTube Studio)
- Go to studio.youtube.com → **Content** → **Live** tab → click your stream (pencil icon).
- **Show more** → **License** section → tick **Allow embedding** → **Save**.
- **Visibility**: Public (or Unlisted). Private can't play on other sites.
- Audience: "No, it's not made for kids". Kids' streams have restricted playback elsewhere.

## 2. Channel defaults, so future streams work too
- Studio → **Settings** → **Upload defaults** → **Advanced settings** → tick **Allow embedding** → **Save**.
- Studio → Create → **Go live** → **Stream** tab → **Edit** → tick **Allow embedding**. This sets it on the reusable stream setup.

## 3. Check (me, after you've saved)
- Load the ukstats.co.uk home page in a test browser, press play in the UKStats Live box, and confirm the stream plays instead of showing "Video unavailable / Playback on other websites has been disabled".
- If it still fails, also check the channel is verified by phone. Unverified channels can have restricted embedded live playback.
