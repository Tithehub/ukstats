## Sharper YouTube watermark

The last one was blurry because it was a screenshot shrunk down. This one gets redrawn from scratch as clean vector shapes.

- Draw the logo again using the site's exact bar sizes, colours (white "UK", pale-blue "Stats" and bars) and the site's Archivo font, so it matches the header exactly but with perfectly sharp edges.
- Change the layout to fit a square: bars on top and "UKStats" underneath, filling the square, so it stays readable in YouTube's small corner spot. (The old one was wide and thin.)
- Add a very faint dark edge around the logo so it still shows on bright footage, without making a box.
- Export with a fully see-through background in three files:
  - ukstats-youtube-watermark-1000.png: 1000×1000, the best one to upload. YouTube accepts larger square images and scales them down itself, which looks sharpest.
  - ukstats-youtube-watermark-150_v4.png: exactly 150×150, rendered at high resolution first and then reduced.
  - ukstats-youtube-watermark.svg: the vector master, for any future use.
- Check each one zoomed in, and over dark, bright and busy backgrounds, before sending.
