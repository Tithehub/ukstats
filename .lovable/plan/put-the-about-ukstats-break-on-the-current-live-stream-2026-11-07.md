# Put the "About UKStats" break on the current live stream

You don't need to start a new stream. Keep the current one running.

## Steps
1. Publish the site. This puts the new break on ukstats.co.uk/globe/broadcast.
2. The stream page checks for a new version every 5 minutes and reloads itself, so OBS picks up the change on its own. The YouTube stream stays live the whole time.
3. If the break hasn't appeared after about 5 minutes, right-click the UKStats Browser source in OBS and choose Refresh. The stream does not stop.
4. You'll see the break at the next :00, :15, :30 or :45.
