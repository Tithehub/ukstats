# Improving UKStats — recommended next steps

Ranked by how much each helps visitors and income, keeping the free-stats, no-made-up-figures rules.

## 1. Finish and publish what's built (first)
- Publish so share pictures, the Business Directory review badges, the inquiry/book buttons and stream cards go live on ukstats.co.uk.
- Check the full sponsor flow while signed in: a sponsor saves a review link, then an admin approves it.
- Re-run the security scan to confirm the 7 fixed issues are gone.

## 2. Keep visitors for more than one page
- At the bottom of each figure page, add "Related figures" (for example, small boats leads to asylum claims and to the migration globe).
- Add a "Follow this figure" email alert for when a figure updates. It's free for visitors, and it builds your own mailing list.
- Speed up the slowest pages (home, globe) so people on phones don't give up.

## 3. Free growth (you post it yourself)
- Start Day 1 of the two-week posting plan that's already saved.
- Make a "This week's releases" page that lists upcoming official release dates. Journalists and Reddit users link to pages like that.
- Add short, plain-English pages answering common questions ("How many small boats this year?"), using only published figures.

## 4. Make the stream dependable
- Run the 24/7 stream from a cheap cloud server instead of the MacBook, with a watchdog that restarts it.
- Fix the presenter's voice for the stream computer without letting the public run up voice costs.

## 5. Income
- Make the sponsor sign-up and Rent UKStats pages clearer, with real screenshots and one obvious button.
- Offer a free one-page sample of the daily report in return for an email, to grow report sales.

## Technical notes
- Related figures reuse the existing register categories. Alerts need a subscribers table plus sending email from your own domain.
- Release-calendar data comes from the "next release" dates already stored for each metric.
- Stream voice: a short-lived signed token for the broadcast page, instead of a full sign-in.
