# Why the stills looked so much worse than the example video

## They were made in two completely different ways
- **The example video** was made by a video maker, the same way you'd make a film. It paints each frame as a picture, so it can draw anything that looks good: a glowing globe, smooth light trails, a moving presenter. It doesn't have to be accurate, because it isn't showing real data.
- **The stills** were photos of the real stream page: a working web page showing real figures and headlines. That page is built from code, panel by panel, and it can only look as good as that code is.

## Why the real page fell so far short
- **The look wasn't copied closely enough.** I built the page as a rough version of the example: the right colours and layout, but none of the glow, depth, soft lighting and polish the video maker added. So it looked flat and cheap next to it.
- **The machine I used to capture it was too weak.** It couldn't draw the 3D globe and the animations properly. The globe went missing, the counters froze at zero, and the effects never got going.
- **It had layout mistakes.** Cards covered the presenter, labels were cut off, the tiles were tiny, and the headline strip was cut mid-word. A designed video never has these, because every frame is composed by hand.
- **The presenter is a still photo.** In the video she's animated as part of the image. On the page she's a cut-out picture with only small movements, so she looks pasted on.

## In short
The example is a polished picture of what the stream could look like. The stills showed the real, working page, which is still an unfinished rough version, captured on a machine that couldn't run it properly. That's why the gap was so big. I should have explained this before sending them.
